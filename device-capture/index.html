QUESTIONS

Good to know.

Can I install the Android app right now?

Public Google Play access has not yet been confirmed for all visitors. Existing authorized testers should continue using their approved testing access. A public download button will be added once installation is verified.

Do I need to create a CableMint account?

Sign in with your CableMint account to use connected project features. You can create an account through the web workspace.

Does it work without service?

Device Capture supports an offline queue for captured records. When a connection returns, queued changes can sync to the web workspace.

Is Device Capture the same as the spreadsheet downloads?

No. Device Capture is the Android field companion; Field Tools is the browser-based workspace; the downloadable spreadsheets are separate products sold in the CableMint store.
